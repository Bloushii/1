# فحص الذهب اليومي

القواعد ونتيجة المحاكاة بـ `gold/STRATEGY.md`. الطريقة الحالية **DCA ذكي** (`mode: dca` بالسجل): `signal` يقول متى وكم، وما فيه بيع. السجل بـ `gold/ledger.json`. المستخدم ينفذ اللي تقوله بالضبط، فالقرار لازم يكون واضح بعدد القرامات والسعر.

1. **حدّث الأسعار:** نزّل `https://github.com/shikerkattiyar11-debug/xauusd-gold-data.git` بـ `git clone --depth 1` بمجلد مؤقت، وانسخ `data/xauusd_1d.csv` على `gold/data/xauusd_1d.csv`. تأكد إن آخر سطر تاريخه اليوم أو آخر يوم تداول.
2. **سعر الدار:** إذا المستخدم عطاك سعر الدار، سجله بـ `python3 gold/gold.py quote <شراء> <بيع> <السعر العالمي>`.
3. **القرار الفني:** شغّل `python3 gold/gold.py signal [سعر بيعك للدار]`.
4. **الفيدرالي والأخبار:** دوّر على آخر قرار للفيدرالي وتصريحاته واحتمالات الفايدة، والدولار، والتضخم والنفط، وبيانات أمريكا الجاية، والجيوسياسة، وآخر كلام المحللين (Reuters وKitco وFXStreet والبنوك).
   - إذا فيه خبر سلبي قوي للذهب (رفع فايدة مفاجئ، أو بيانات تضخم عالية خلال 24 ساعة)، نزّل حجم الشراء درجة أو ألغه، وقل السبب.
   - الأخبار ما تضيف شراء ما طلّعته `signal`، وما تلغي بيع طلّعته.
   - **تنبيه الخبر:** إذا فيه خبر ممكن يوتر السعر خلال 24 ساعة، أو صار خبر قبل شوي (قرار الفيدرالي، CPI، PCE، الوظائف، تصعيد حرب، حركة أكثر من 2% باليوم)، اكتب تنبيه واضح بسطر: "لا تشتري"، "لا تبيع"، أو "انتظر لين يطلع الخبر الساعة كذا"، مع السبب والوقت بتوقيت الكويت. إذا ما فيه شي، خله فاضي.
5. **القرار:** واحد بس، أول سطر بالرد:
   - 🟢 **اشتر X قرام** بحدود السعر. X هو المجموع (تداول + تخزين + أرباح).
   - 🔴 **بيع X قرام** بحدود السعر، والربح.
   - **المستخدم ما يبي يسمع "تداول" ولا "تخزين" ولا "محفظة دائمة"**: قله الرقم الكلي بس، والتقسيم يبقى داخلي بالسجل.
   - ⚪ **لا تسوي شي اليوم**، والسبب بسطر، والسعر بالدينار اللي يقرب عنده الشراء.
6. تحت القرار: المعدل الفني، وملخص الأخبار بثلاث نقاط، والمصادر كروابط.
7. **حدّث الصفحة** (https://claude.ai/artifact/UriwTRxMmX414R4gkkW1ub):
   - شغّل `python3 gold/export.py "<ملخص الأخبار بسطرين>" "<تنبيه الخبر أو فاضي>" [سعر بيعك للدار]`.
   - ارفع `gold/out/decision.json` و`gold/out/prices.json` و`gold/out/trades.csv`، كل واحد بـ `Artifact` (`url` الصفحة، `asset: true`).
   - حدّث `datasets/decision` و`datasets/prices` و`datasets/trades` بـ `ArtifactData` `update`: الـ `source.url` الجديد، و`updated: {at, by}`، و`if_version` من آخر قراءة.
   - **الصفحة الخفيفة** (هذي اللي تنفتح على آيفون المستخدم، https://claude.ai/artifact/P8fppirDYGjeXHmPqedogU): شغّل `python3 gold/page.py`، وانشر `gold/out/page.html` بـ `Artifact` مع `url` هذي.
8. إذا المستخدم أكّد إنه اشترى أو باع، سجّلها بالسعر الفعلي: الشراء بـ `python3 gold/gold.py bought <السعر> [القرامات]` (يوزعها لحاله حسب قرار اليوم)، والبيع بـ `sell <رقم الصفقة> <السعر>` لكل صفقة طلعت ببيع اليوم. سوّ commit وpush للسجل وملف الأسعار.

آخر سطر دايماً: "هذا تحليل آلي وليس نصيحة مالية مرخصة."
