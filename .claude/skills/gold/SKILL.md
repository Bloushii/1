# فحص الذهب اليومي

القواعد كاملة بـ `gold/STRATEGY.md`، اقراها أول. السجل بـ `gold/ledger.json`.

1. **السعر**: دوّر على سعر الذهب العالمي الحين (XAU/USD)، وشغّل `python3 gold/gold.py price <USD>`. إذا المستخدم عطاك سعر الدار (شراء وبيع)، سجله بـ `python3 gold/gold.py quote <شراء> <بيع> <USD>` عشان تتعاير النسب على متوسط كل أسعار الدار المسجلة.
2. **الفيدرالي** (35%): موعد الاجتماع الجاي، آخر قرار وآخر تصريح، احتمالات FedWatch، عوائد السندات الحقيقية.
3. **الأخبار العالمية** (25%): الدولار، النفط والتضخم، بيانات أمريكا الجاية (CPI/PCE/NFP) ومواعيدها، الجيوسياسة، البنوك المركزية، تدفقات ETF.
4. **الشارت** (25%): المتوسطات 20/50/100/200، RSI، أقرب دعم ومقاومة.
5. **المحللين** (15%): آخر شي قالته Reuters وKitco وFXStreet والبنوك الكبيرة.
6. شغّل `python3 gold/gold.py status <سعر بيعك للدار>`.
7. طبّق قواعد STRATEGY.md وطلّع قرار **واحد**:
   - 🟢 **اشتر X قرام**: مع سعر الدخول بالدينار والهدف.
   - 🔴 **بيع قرام من الصفقة #N**: مع الربح.
   - ⚪ **لا تسوي شي اليوم**: مع السبب بسطر، والسعر بالدينار اللي يصير عنده الشراء منطقي.
8. اعرض جدول التقييمات الأربعة والمعدل، والمصادر كروابط.
9. إذا المستخدم أكّد إنه اشترى أو باع، سجّلها بـ `buy`/`sell`، وسوّ commit وpush.

آخر سطر دايماً: "هذا تحليل آلي وليس نصيحة مالية مرخصة."
