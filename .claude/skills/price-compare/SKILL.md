# مقارنة الأسعار: اكس سايت / يوريكا / بيست اليوسفي

## الخطوات
1. حوّل سؤال المستخدم لكلمات بحث إنجليزية قصيرة: الموديل + السعة إن ذكرها.
   أمثلة: "ايفون ١٧ برو ماكس ٢٥٦" → `iphone 17 pro max 256` ، "سامسونق الترا ٢٥" → `galaxy s25 ultra`.
2. شغّل:
   ```bash
   node .claude/skills/price-compare/compare.js "iphone 17 pro max 256"
   ```
   يرجع JSON فيه لكل محل قائمة `items` (الاسم، السعر الحالي `price`، والسعر قبل الخصم `was`).
3. فلتر النتائج: خذ الجهاز نفسه فقط (نفس الموديل والسعة)، واستبعد الكفرات والشواحن والإكسسوارات.
   إذا اللون يفرق بالسعر، اذكر أرخص لون.
4. جاوب بالعربي (لهجة خليجية) بجدول:

   | المحل | الجهاز | السعر |
   |---|---|---|
   | اكس سايت | ... | ... د.ك |
   | يوريكا | ... | ... د.ك |
   | بيست اليوسفي | ... | ... د.ك |

   لا تضيف عمود "قبل الخصم" (المستخدم ما يبيه): السعر الحالي بس.
   وبعده سطر واضح: **الأرخص: <المحل> بـ <السعر> د.ك** والفرق عن اللي بعده.
5. إذا محل ما طلع فيه الجهاز أو صار خطأ، قول ذلك بصراحة ولا تخترع سعر.

## ملاحظات
- الأسعار من صفحات البحث وقت السؤال، وممكن تتغير.
- المواقع تحتاج تكون مسموحة في إعدادات الشبكة للبيئة:
  `www.xcite.com`, `www.eureka.com.kw`, `best.com.kw`, `mrflex.best.com.kw`.
- يوريكا: بحثهم ما يشتغل من هنا، فالأداة تفتح قسم الهواتف الذكية وتفلتر على الماركة (IPHONE / SAMSUNG). يعني يوريكا يغطي الهواتف بس، مو الإكسسوارات أو الأجهزة الثانية.
- يوريكا يبيع نسخ "Japanese Vr" و"American Version": نبّه المستخدم إنها مو النسخة الخليجية (الضمان يختلف، والياباني صوت الكاميرا ما ينطفي). قارن النسخة الخليجية/العادية أولاً.
- بيست يحط سطر عنوان مثل "Iphone 17 Pro Result (1803)": هذا مو جهاز، تجاهله.
- إذا محل ما طلع فيه إلا إكسسوارات، معناته الجهاز مو متوفر عندهم حالياً.
- لسامسونق لا تحط كلمة "galaxy" في البحث: اكس سايت يكتب "Samsung S25 Ultra" بدونها فما يطلع شي. استخدم مثلاً `s25 ultra 256`.

## صفحة "وين أرخص" (الصفحة اللي على الشاشة الرئيسية)
- الرابط: https://claude.ai/artifact/QhLoe8VnMyRApdJ6tis6Qg (ملف الصفحة: نسخة منها في هالمحادثة؛ للتعديل اقراها بأداة Artifact أول).
- البيانات في قاعدة بيانات الصفحة:
  - `prices/all` = `{ rows: { <id>: {brand, model, storage, xcite, eureka, best} }, updatedAt, stats, problems }` و كل محل `{price, color}` أو `null`.
  - `meta/refresh` = حالة التحديث: `requested` / `running` / `done` / `error`.
  - `requests` = أجهزة كتبها المستخدم في مربع "أضف" (حقل `text`).
- زر "حدّث الأسعار" في الصفحة: يفتح جلسة Claude Code على السحابة (موصل Claude Code Remote → `create_session`) على هالفرع، والجلسة تشغّل `update.js` بس (مسموح بدون موافقة في `.claude/settings.json`) وما تلمس بيانات الصفحة. `update.js` يطبع سطر `PRICES_JSON_BEGIN{...}PRICES_JSON_END`، والصفحة تقراه من سجل الجلسة (`list_events`) كل ٣٠ ثانية وتحفظه في `prices/all` بنفسها، وتمسح الطلبات، وتأرشف الجلسة. لو الزر فشل، `meta/refresh` فيه `code` و`detail` للسبب.
- لما المستخدم يقول "حدّث الأسعار" في المحادثة، سوّ نفس خطوات الزر:
  1. اقرأ `requests` وحوّل كل طلب لكلمة بحث إنجليزية قصيرة (بدون "galaxy").
  2. `node .claude/skills/price-compare/update.js /tmp/prices.json "<بحث إضافي>" ...` (ياخذ ٥-٨ دقايق، يشغّل المواقع واحد واحد ويعيد المحاولة لو محل رجع فاضي).
  3. `set` على `prices/all` من الملف (مع `if_version`)، وامسح الطلبات اللي خلصت، وحدّث `meta/refresh`.
- `update.js` يخلي بس الأجهزة اللي لها سعر في اكس سايت أو بيست (عشان فيه مقارنة)، أو اللي المستخدم طلبها بالاسم. يتجاهل الإكسسوارات، والنسخ اليابانية/الأمريكية، واللي مكتوب عليها "OUT OF STOCK" في بيست.
- لو نزل موديل جديد (مثلاً ايفون 19)، ضيف كلمة بحثه في `QUERIES` داخل `update.js`.
- **بالجوال (تطبيق الآيفون) موصل Claude Code ما يشتغل**: الزر يسجّل `meta/refresh.status = "queued"` بس. فيه مهمة مجدولة (`trig_017VPbVGFejF5mKsDDXhA22R`) تصحّي هالجلسة **مرة وحدة باليوم الساعة ٩:٠٧ الصبح** بتوقيت الكويت وتحدّث الأسعار (ومعها الطلبات المسجلة). المستخدم ما يبي فحص كل ساعة؛ للتحديث الفوري يكتب "حدّث الأسعار" بالمحادثة.
- الأجهزة اللي المستخدم يبيها هالفترة: ايفون 18 Pro / Pro Max و17 / 17 Pro / Pro Max، وسامسونق الالترا بس (S26 / S25 Ultra). `update.js` يشيل الباقي إلا لو انطلب بالاسم.
- **إيقاف آخر الشهر:** لما المستخدم يقول إنهم صكّروا حسابات الشهر، وقّف المهمة اليومية (`update_trigger` على `trig_017VPbVGFejF5mKsDDXhA22R` مع `enabled: false`)، ورتّب إنها ترجع تشتغل أول يوم من الشهر الجاي (رسالة `send_later` لهالجلسة يوم ١ الصبح تفعّلها، أو `enabled: true` لو المستخدم طلب). وخلال الإيقاف لا تحدّث الأسعار ولا حتى لو ضغط الزر، إلا لو طلب صراحة.
