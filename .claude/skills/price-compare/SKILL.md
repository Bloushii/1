# مقارنة الأسعار: اكس سايت / يوريكا / بيست اليوسفي

## الخطوات
1. حوّل سؤال المستخدم لكلمات بحث إنجليزية قصيرة: الموديل + السعة إن ذكرها.
   أمثلة: "ايفون ١٧ برو ماكس ٢٥٦" → `iphone 17 pro max 256` ، "سامسونق الترا ٢٥" → `galaxy s25 ultra`.
2. شغّل:
   ```bash
   node .claude/skills/price-compare/compare.js "iphone 17 pro max 256"
   ```
   يرجع JSON فيه لكل محل قائمة `items` (الاسم، السعر الحالي `price`، والسعر قبل الخصم `was`).
3. فلتر النتائج: خذ الجهاز نفسه فقط (نفس الموديل والسعة)، واستبعد الكفرات والشواحن والإكسسوارات.
   إذا اللون يفرق بالسعر، اذكر أرخص لون.
4. جاوب بالعربي (لهجة خليجية) بجدول:

   | المحل | الجهاز | السعر |
   |---|---|---|
   | اكس سايت | ... | ... د.ك |
   | يوريكا | ... | ... د.ك |
   | بيست اليوسفي | ... | ... د.ك |

   وبعده سطر واضح: **الأرخص: <المحل> بـ <السعر> د.ك** والفرق عن اللي بعده.
5. إذا محل ما طلع فيه الجهاز أو صار خطأ، قول ذلك بصراحة ولا تخترع سعر.

## ملاحظات
- الأسعار من صفحات البحث وقت السؤال، وممكن تتغير.
- المواقع تحتاج تكون مسموحة في إعدادات الشبكة للبيئة:
  `www.xcite.com`, `www.eureka.com.kw`, `best.com.kw`, `mrflex.best.com.kw`.
- يوريكا: بحثهم ما يشتغل من هنا، فالأداة تفتح قسم الهواتف الذكية وتفلتر على الماركة (IPHONE / SAMSUNG). يعني يوريكا يغطي الهواتف بس، مو الإكسسوارات أو الأجهزة الثانية.
- يوريكا يبيع نسخ "Japanese Vr" و"American Version": نبّه المستخدم إنها مو النسخة الخليجية (الضمان يختلف، والياباني صوت الكاميرا ما ينطفي). قارن النسخة الخليجية/العادية أولاً.
- بيست يحط سطر عنوان مثل "Iphone 17 Pro Result (1803)": هذا مو جهاز، تجاهله.
- إذا محل ما طلع فيه إلا إكسسوارات، معناته الجهاز مو متوفر عندهم حالياً.
